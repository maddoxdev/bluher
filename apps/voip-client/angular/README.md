# VoIP Client (Angular)

Папка для Angular SPA/PWA клиента звонков.

## Рекомендуемый старт

```bash
npx @angular/cli@latest new . --routing --style=scss --standalone
```

## Важные модули

- `core/services/auth.service.ts`
- `core/services/signaling.service.ts`
- `core/services/webrtc.service.ts`
- `features/calls/*`
